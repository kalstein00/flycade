# T13 평가 영상과 실제 회로 관측의 동기 재생

평가의 첫 에피소드 영상 구간에 행동을 선택한 **동일 forward**의 원본 화면, 정책 입력 프레임, 선택 부분그래프의 마지막 상태 벡터, 행동 확률과 선택을 저장한다. 추가 forward나 난수 추첨은 하지 않는다. 초기·주기·명시적 snapshot 평가에 같은 경로가 적용된다. 기존의 정책 선택/사용자 pin 경로에서 보존본을 평가할 수 있다.

## 저장 계약

- 게임 시간 20 emulator frames 간격을 목표로 행동 경계에서 기록한다. 기본 action repeat 4에서는 약 ⅓초 간격이다. 다른 action repeat에서는 다음 행동 경계까지 늦어질 수 있고 실제 frame을 기록한다.
- 첫 에피소드만, 기본 15초/45표본. 평가 video_seconds 상한 60초이면 최대180표본. 표본 JSON 누적 크기는16 MiB 이하이며 초과 시 기록 실패를 보고한다. 그래프는 실제 사용 노드 중 최대128개, 연결512개, 상태 벡터 요약은 기존 관찰 화면과 같다.
- `evaluations/<ID>/observations.json.gz`는 gzip level9로 저장한다. 임시 파일 flush/fsync→원자 rename→디렉터리 sync 후 공개한다. 평가 보고서 `replay`에 버전, 경로, SHA-256, 크기, 개수, 상한, 오류를 남긴다. 기록 실패면 해당 평가는 실패로 표시하고 최고본 선정에서 제외한다. 이전 정상 학습 체크포인트를 수정하지 않는다.
- `live.json`은 같은 실제 표본의 최신 1개만 최대 벽시계3Hz로 갱신한다. 평가가 첫 영상 구간을 지난 뒤에는 마지막 표본을 유지한다. 종료/프로세스 중단은 별도 표시한다. 전체 학습 프레임이나 모든 뉴런의 이력을 저장하지 않는다.

영상 시각은 `행동 적용 전 누적 emulator frames / 60`이다. VP9 영상 첫 프레임은 첫 emulator step 후 화면이며12fps로 줄어든다. 따라서 한 emulator frame의 시작 오프셋과 영상 프레임 양자화가 있고, 표본 사이의 활동은 복원하지 않는다. 브라우저는 영상 시각 이전 마지막 표본을 **20/60초 미만** 동안만 사용한다. 표본 누락이나 탐색 중에는 패널을 비우고 데이터 없음을 표시한다. 그래프·입력·행동은 이미지 디코딩 후 함께 교체한다.

## 사용

`flycade live RUN`을 열고 **평가 관찰·이력**으로 이동한다. 비교 화면의 **회로 이력과 함께 재생**도 같은 평가본을 연다.

- **기록 영상과 관찰 이력**: native video 재생/일시정지/탐색. 노드·표·필터·확대·입력 프레임·행동 확률 이력을 읽기 전용으로 탐색한다. 가로축은 평가 처리의 벽시계가 아니라 기록된 게임 시간이다.
- **고정 평가의 최신 관측**: 선택한 평가의 게임 화면/회로/입력/행동만 표시한다. 현재 학습 스트림과 혼합하지 않는다. 첫 에피소드 영상 구간을 지난 뒤에는 마지막 표본이다.
- 이력이 없는 예전 영상, 파일 누락·손상, 기록 실패는 데이터 없음/오류로 표시한다. 최신 학습 회로를 대신 붙이지 않는다. Run/평가 변경 중 늦게 도착한 응답은 폐기한다.

영상과 회로의 pause/seek/선택은 trainer나 학습 RNG를 변경하지 않는다. 파일 정리와 기간 보존은 후속 #16에서 이 참조를 사용한다.

## 검증 증거

CLI/영속 artifact 검사에서 저장 입력을 실제 정책에 다시 통과시켜 상태 벡터와 행동 확률을 대조했다. 게임 시각0·⅓·⅔초와3개 표본 상한을 검사했다. 기록 발행 경로를 디렉터리로 막는 공개 파일시스템 결함에서 오류/프로세스 정리/기존 checkpoint 바이트 유지도 확인했다.

Chromium 검사에는 재생/정지/앞뒤 탐색, 표본 누락, 노드 키보드 선택, 늦은 HTTP 응답 배제, 다른 평가본/모드 전환, 기존 영상 이력 없음, 실제 실행 중 고정 평가 스트림,1920/1280/390px overflow, 전체 checkpoint 바이트 불변을 포함했다.

실제 NES/RTX5090 Run은 `reports/t13-replay-001/run`이다. 검증용4 updates/평가 간격2로 초기·2·4의3회 평가와 새 프로세스 재개를 실행했다. [T13-evidence.json](T13-evidence.json)에 영상 PTS 및 실제 전이 frame/action과 표본 대응을 확인한 결과를 남겼다.15초 클립은 각45표본, 압축 관찰 기록 약1.28 MB, VP9 영상 약48~58 KB였다. 짧게 종료한 클립은11표본·관찰 약302 KB·영상 약16 KB다. 관측 저장 크기는 영상과 별개다. 이 실행은 동기화 검증이며 학습 향상의 증거가 아니다.

화면 증거는 `t13-screens/replay-{1920,1280,390}.png`와 `fixed-evaluation-1280.png`다. native video가 실제로 재생/탐색된 후 캡처했다.

검토: Standards 문서 규칙 위반0, 비차단 휴리스틱2(행동 행 렌더러 중복/inspector 이력 API 집중화). Spec의 실패 원인 숨김1건을 브라우저 RED로 확인한 뒤 수정했고 재검토에서 해소됐다. UI는 ship, 문서화는 기존 디자인 유지(No changes)다. mypy33개 소스에서 오류가 없다.

전체 회귀 검사94개 통과(554.63초). 실제 ROM 검사를 포함했으며, 소스 변경 없이 마지막 전체 검사를 완료했다.
