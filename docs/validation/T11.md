# T11 — 회로·뉴런 탐색

실제 정책의 동일 forward에서 수집한 bounded 부분집합을 탐색한다. 노드 클릭/Enter/Space와 뉴런 표 버튼이 같은 선택을 공유한다. 선택 노드와 연결은 윤곽선으로 강조한다. 입·출력·내부군/선택 연결 필터와0.5배 단위1~3배 확대/축소는 브라우저만 바꾸며 정책 topology와 추론/학습에 쓰는 상태를 변경하지 않는다. 확대는 선택 노드를 중심으로 하며 선택 전에는 구조도 중앙을 중심으로 한다.

표는 현재 표시 범위의 |활성 평균| 상위10개를 기본으로 한다. 선택 뉴런은 순위나 표시군 밖으로 나가도 추가 행과 상세에서 유지한다. 원본 root ID는 문자열로 보존한다. 종류는 실제 cell_type, 영역은 데이터에 있는 경우만 표시하며 현재 그래프 산출물에 없는 영역은 ‘알 수 없음’이다. 그림은 고정 구조도로 해부학 위치가 아니다. 입력 원·내부 마름모·출력 사각형 및 문자 범례로 구별한다.

활성값은 마지막 tanh 전파 단계의 상태 벡터 산술평균이며−1~+1의 무차원 값이다. |평균|≥0.1 개수를 집계하며 생물학적 전압·발화나 위험도로 해석하지 않는다. 0은 실제0, 누락은 관측값 없음, 미상은 주석 없음이다. 미사용은 정책 그래프 밖으로 관측하지 않는다. 정책에 사용하지만 화면에서 빠진 노드는 미표시이며 미사용/0과 다르다. 실제 사용/표시/제외 노드·연결 수와 기본 부분집합 선정 규칙을 표시한다.

최근 이력은 브라우저에만 최대30초/90개 표본의 노드 평균·행동 확률을 보관하며 이미지 이력은 저장하지 않는다. 선택 뉴런이 없으면 관측 부분집합의 평균, 선택하면 해당 뉴런 평균을 표시한다. 행동은 선택 상자로 고정한 행동 ID의 확률을 표시한다. 세로축은 각각−1~+1 무차원 평균과0~1 확률, 가로축은 마지막 표본 대비 초다. 누락값·건너뛴 sequence·두 표본 간격을 넘긴 시간·역행 시각을 선으로 잇지 않는다. Run/worker/세션이 바뀌면 이력을 초기화한다. 브라우저를 닫으면 이력이 사라지며, 저장 영상과 동기 관찰 재생은#14 범위다. 학습 측 queue1/latest1/history0 계약은 유지한다.

누적 입력은 실제 uint8 전처리 픽셀의 작은 연속 이미지 또는 특정 프레임으로 확인한다. 모델 내부에서/255하며 표시용 역정규화는 없다. 학습/현재 세션/정책 시점/샘플 ID와 저장 상태는 기존 coherent bundle 계약을 따른다.

## 여러 Run과 worker

```bash
uv run --offline --locked --extra train flycade live reports/run-a --run reports/run-b --run reports/run-c
```

명시적으로 등록한 최대32개 Run만 읽는다. 상단 Run과 worker 선택은 읽기 전용이다. 실제 검증 프리셋은 worker0 한 개이며 viewer를 조작한다고 환경 수가 늘지 않는다. 별도 관측 producer의 `live/workers/<1..63>/latest.json`을 같은 envelope 계약으로 읽을 수 있고 다중 worker는 통제 fixture로 검사한다. 선택 시 진행 중 HTTP 요청을 중단하고 화면·이력을 지운다. Run/worker/세션/generation/sequence/정책 버전·진도의 역행을 검사하며, 이미지 디코드 중 전환됐을 때도 이전 DOM을 다시 공개하지 않는다.

## 검증 경계

실제 로컬 HTTP/Chromium과 CLI 산출물에서 정책값 대응, 원본 ID, 키보드 선택, 표시 필터, 확대, 입력 프레임, 상위 순위에서 빠진 선택 유지, 활성 누락과0,90개 상한 및 결측 단절을 검사한다. 통제된 관측 파일은 순위·결측·worker 전환 경계를 재현하기 위한 fixture이며 실제 학습으로 얻은 값처럼 검증 보고서에 기록하지 않는다. 늦게 전달되는 HTTP 응답과 잘못된 worker/Run 표본을 모두 거부한다. 실제 학습 중 UI 조작/연결 해제/창 닫기 뒤 모델 파라미터와 학습 RNG가 관측을 끈 동일 seed Run과 일치함을 검사한다.
